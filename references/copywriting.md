# 文案口径

PPT 上的字和图注的字，是**给听众回去查的**；讲稿的字是**当场说的**。两者口径不同，但都要过一个关：**这句话是真的吗。**

---

## 四条底线

### 1. 不确定的，不写

论文里查不到的数据、作者没说的机理、你自己推的因果关系 —— **一律不写**。

> ❌「这说明 Mo³⁺ 的掺杂上限源于离子半径失配」（文中没这么说）
> ✅「文中只观察到 3.8% 以上出现猝灭，没有给出定量模型」

组会上被追问一句「这个结论原文有吗」，就是硬伤。空着不写没人怪你，写错了要当场认。

### 2. 数字必须回原文核

引任何数值之前，回 PDF 里找到那一句。

- `4.4 meV` 不是 `44 meV`
- `9.0 ms` 不是 `9 ms`（有效数字是信息）
- `0.05 Å` 不是「大概 0.1 Å」
- `1095 nm` 是发射主峰，`1081 nm` 是零声子线 —— **两者差 14 nm，混淆了整段解释就崩**

### 3. 除第 2 页外，全部译成中文

用户 2026-11-02 明确要求：「除了第二页类封面全英，其他的题注和长英语都要中文」。

- 第 2 页是论文首页截图，英文原样保留（截图本身没法改）
- 所有图注、说明、表格标题、正文 —— **中文**
- 化学式、单位、人名、期刊名、仪器型号保持原文
- 缩写第一次出现给全称：`EXAFS（扩展 X 射线吸收精细结构）`

⚠️ 不要机器翻译腔。`(a) 掺杂浓度依赖的全局与局域结构` 是人话，`(a) 掺杂浓度依赖的全局和局部结构表征` 是翻译腔。

### 4. 图注必须完整

规范图第 7 条点名了这个：「必须加图注，这是组内通病」。

**完整的意思是：**
- 开头 `图 N` + 空格
- 每个子图 `(a) (b) (c)` 都要有，一个不能跳
- 每个子图一句，说清**它画的是什么**
- 化学式用 `^{}` / `_{}` 标记，转真上下标
- 长度 150–600 字（原稿样本是 144–537 字符英文）

**不完整的样子：**
- ❌ 「图 3 不同掺杂浓度的 XRD」（只说了标题）
- ❌ 「如图所示，掺杂后峰位移动」（"如图所示"等于没说）
- ❌ 只有 (a)(b)，(c)(d)(e)(f)(g) 跳过
- ❌ 40 字打发（`check_deck.py` 会报）

## 词汇

### 用这些

| 场景 | 用 | 不用 |
|---|---|---|
| 解释机理 | 「因为……，所以……」 | 「这得益于……的作用」 |
| 说结果 | 「得到 1095 nm 的发射」 | 「成功实现了……的发射」 |
| 说不足 | 「效率还不高，只有 7.5%」 | 「虽然效率仍有提升空间」 |
| 说反常 | 「这一点和常规的 Kasha 规则不一致」 | 「突破了传统认知」 |
| 转折 | 「但」「不过」 | 「然而，值得注意的是」 |
| 总结 | 「所以」「也就是说」 | 「综上所述」「总而言之」 |

### 禁用

**商业黑话**：赋能、抓手、闭环、落地、护城河、壁垒、赛道、底层逻辑、颗粒度

**模型腔**：
- 「值得注意的是」「需要指出的是」—— 直接说就行
- 「不仅……而且……」连用
- 「在……方面」当万能胶水
- 三连排比：「快速、高效、稳定」
- 「这为……提供了新的思路」—— 每篇论文结尾都能加这句，等于没说

**学术套话**：
- 「具有重要意义」「取得重大突破」—— 意义让数据说
- 「首次」—— 除非原文明确写 first，否则不写
- 「完美解决」—— 没有完美的事

## 标题怎么写

层级标题（页标题、块标题）的任务是**让人知道这页在干什么**，不是好看。

| 类型 | ✅ 好 | ❌ 差 |
|---|---|---|
| 摘要页 | 这篇文章解决了什么问题 | 摘要 |
| 表格页 | 掺杂量的投料与实际结果 | 实验数据 |
| 合成页 | 溶剂热合成：四步走 | 合成方法 |
| 结论页 | 这篇文章留下了什么 | 结论与展望 |

规律：**动词或问句**，不要名词。「这篇文章解决了什么问题」比「研究背景」好，因为听众想知道答案。

⚠️ 但 `figure` 页的 `tag` 保持编号式：`③ 结构`、`④ 发光`。这是原稿的记忆点，也是导航。

---

## 摘要页怎么写

摘要那一段话，拆成 ①②③④⑤，每条**一个小标题 + 一句白话**。

```
① 痛点：d–d 跃迁本来是宽的
   过渡金属的 d 电子与配体强耦合，d–d 跃迁发出来的光很宽，做不了窄带光源。能发窄光的只有稀土的 f–f。

③ 病根：Mo³⁺ 太亲氧
   Mo³⁺ 极易被氧化成 [MoCl₆₋ₓOₓ]³⁻，缺陷一出来，室温发光就全灭了。这是二十年没进展的原因。
```

三条判据：
1. **标题 ≤ 12 字**，用「痛点 / 例外 / 病根 / 解法 / 结果」这种**功能性**的词，不要「研究背景」
2. **正文 ≤ 45 字**，一句一个意思，不堆从句
3. **不抄摘要原文**。摘要写 "Herein, we report..."，你要写「本文在合成时加入次磷酸作还原剂」

⚠️ 编号用 ①②③ 而不是 123。原稿就是这样，而且 ① 比 1. 在视觉上更轻。

## 结论页怎么写

四块，每块一个层面：

```
① 方法层面的贡献      —— 作者做对了什么
② 物理层面的新现象    —— 有什么反常识的观察
③ 应用层面的落点      —— 能干什么，到什么程度
④ 可以追问的地方      —— 哪里还没做透
```

第 ④ 块是**你自己的判断**，不是论文的 conclusion。这是组会汇报的价值所在 —— 你读了之后觉得哪里还能挖。

⚠️ 第 ④ 块要克制。写「为什么 3.8% 就是上限，文中只观察到现象没给定量模型」是好的；写「这个工作完全没考虑成本问题」就是抬杠。

## 化学式与上下角标

**必须用标记，不用 Unicode 字符。**

| 写 | 不要写 | 渲染成 |
|---|---|---|
| `Cs_{2}NaInCl_{6}` | `Cs₂NaInCl₆` | Cs₂NaInCl₆ |
| `Mo^{3+}` | `Mo³⁺` | Mo³⁺ |
| `[MoCl_{6}]^{3-}` | `[MoCl₆]³⁻` | [MoCl₆]³⁻ |
| `^{2}T_{1g}` | `²T₁g` | ²T₁g |
| `cm^{-1}` | `cm⁻¹` | cm⁻¹ |
| `σ^{2}` | `σ²` | σ² |

Unicode 上下标的问题：换个字体就散架，复制到 Word/论文里常变乱码，而且**没法调大小** —— 真上下标字号自动 ×0.72，Unicode 字符固定大小，跟正文一样大，看着别扭。

`lr_common.add_runs()` 和 `build_script.py::add_runs()` 都认这个标记，转成 `baseline="30000"` / `"-25000"` 和 Word 的 `font.superscript`。

⚠️ 讲稿里也要用标记。用户在 Word 里改稿时，真上下标比 Unicode 好编辑。

## 文件与图注命名

`content.json` 里的图片路径用**相对路径**，相对 content.json 所在目录。

```
figs/fig01_ts_diagram.png     图 1
figs/fig02_synthesis.png      图 2
figs/page01_top.png           第 2 页文章首页顶部
```

前缀 `fig0N_` 对应图号，后缀是该图的主题词 —— 三个月后回来还能认出哪张是哪张。

## 自检清单

出稿前对着这个过一遍：

- [ ] 每个 `figure` 页都有 `caption`，且 ≥ 150 字
- [ ] 每个 `caption` 都有全部子图 (a)(b)(c)…
- [ ] 所有化学式用了 `^{}` / `_{}`，没有 Unicode 上下标残留
- [ ] 所有数字回原文核过
- [ ] 除第 2 页外没有整段英文
- [ ] 没有「值得注意的是」「综上所述」「具有重要意义」这类套话
- [ ] 标题是动词或问句，不是名词
- [ ] 结论页第 ④ 块是自己的判断，不是抄 conclusion
- [ ] `presenter` / `date` 是 XX 或用户给的，不是编的
