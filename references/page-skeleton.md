# 页面骨架 —— 一套汇报稿由哪几种页组成

不是「随便排版」，是**七种页型的固定组合**。规范图里每一条要求，落到这里都有一个明确的归属页。

`content.json` 的 `slides` 数组就是这个顺序，`build_deck.py` 按 `type` 字段分发。

---

## 页序总览

```
1  封面                 cover            由 meta 生成，不用写进 slides
2  文章首页 + 作者信息   paper_home       spec["paper_home"]，不写进 slides
3  摘要精读             summary          ← 规范③
4  实验原料/条件        table
5  合成方法             text             ← 规范⑥
6+ 主图页  ×N           figure           ← 规范③④⑤⑦
末 结论                text
末 致谢                thanks           ← 规范⑧，spec["thanks"]，不写进 slides
```

主图页占全篇 **70% 以上的页数**。这是文献汇报，不是综述讲座 —— 图是主角。

样例（Mo³⁺ 那篇论文）出来是 13 页：封面 / 文献来源 / 摘要 / 图1 概念 / 表格 / 合成 / 图2 / 图3 / 图4 / 图5 / 图6 / 结论 / 致谢。

---

## cover 封面（规范①）

由 `meta` 生成，三个东西必须有：**标题 / 汇报人 / 时间**。少一个就是漏项。

```json
"meta": {
  "presenter": "",
  "date": "",
  "cover_text": "文献汇报",
  "subtitle": "论文中文译名\n可以两行"
}
```

- `presenter` / `date` 留空 → 版面显示 `XX`。**绝不替我编人名或日期。**
- 用户提前给了就填进来，或者命令行 `--presenter` / `--date` 覆盖。
- `subtitle` 可选，主标题下面一行 18pt 灰，让人一眼知道讲的是哪篇。

---

## paper_home 文章首页（规范②）

第二页固定放**论文 PDF 第一页的顶部截图**，右边配作者信息卡。

```json
"paper_home": {
  "image": "figs/page01_top.png",
  "authors": [
    {"role": "通讯作者", "name": "Angshuman Nag", "note": "IISER Pune"},
    {"role": "第一作者", "name": "...", "note": "..."}
  ],
  "highlights": ["期刊：Angew. Chem. Int. Ed. 2025, e19144",
                 "DOI：10.1002/anie.202519144",
                 "一句话贡献：..."],
  "caption": "可选，图注"
}
```

**这一页是全篇唯一允许全英文的页**（用户 m00592 明确说过：「除了第二页类封面全英，其他的题注和长英语都要中文」）。截图本身是英文，译了就对不上原文。

截图裁剪：`crop_figures.py sample.pdf --crop "1,0.035,0.020,0.965,0.430" -o figs/page01_top.png --dpi 220`
要求完整包含标题、作者列表、单位、期刊名与 DOI，不要把页码、页眉水印裁进来。

作者卡内容**没有把握就别编**。查不到就只写单位，宁可空着也不能虚构。

## summary 摘要精读（规范③）

摘要那一段话拆成 ①②③④⑤ 编号条目，每条一个短标题 + 一句白话。

```json
{"type": "summary", "heading": "这篇文章解决了什么问题",
 "items": [{"head": "宽谱线做不了窄带源", "text": "d–d 跃迁键长变化大，振动一参与就摊开"}]}
```

原稿用的是「①②③④⑤ + 手画直线下划线」—— 下划线是**手画的直线**，不是文字下划线，线的长度和文字永远对不齐。新做法：靠序号和缩进区分，**不画下划线**。

写法要求：
- 每条标题 ≤ 12 字
- 每条正文 ≤ 40 字，一句一个意思
- 不要抄摘要原文，要**翻译成人话**

---

## table 实验数据页

原料表、发光参数表、对比表都走这个页型。原稿是光板表，照原样保留。

```json
{"type": "table", "heading": "掺杂量的投料与实际结果",
 "columns": ["投料比例", "ICP-MS 实测"],
 "rows": [["2 %", "0.6 %"], ["6 %", "3.8 %"]],
 "caption": "表格下方 11pt 灰的说明文字"}
```

- 表格上边从 **y=1.62** 起（原稿浮在页面正中，用户要求严格照样本）
- 列宽按内容自动估算，不等分
- 图注放表格正下方 0.18in

## text 文本页（合成方法、结论等）

原稿第 6 页那种。要点是**分块**：每块一个小标题 + 一段话，块之间留白。

```json
{"type": "text", "heading": "溶剂热合成：四步走",
 "blocks": [{"head": "① 前驱体", "text": "CsCl、NaCl、InCl3 和少量 MoCl3 溶于盐酸…"}]}
```

规范⑥说「初期可参考范文模仿写作」—— 合成方法段落有固定套路：

```
前驱体与溶剂  →  加入什么、溶于什么、浓度多少
关键步骤      →  还原/回流/结晶，温度与时间
后处理        →  离心、洗涤、干燥条件
得到的产物    →  形貌、粒径、产率
```

按这个四段走，通顺且不漏项。

## figure 主图页（规范③④⑤⑦，最重要）

一页 = **一张图 + 一段完整图注**。

```json
{"type": "figure", "heading": "③ 结构", "tag": "③ 结构",
 "image": "figs/fig03_xrd_xas.png",
 "caption": "图 3 (a) Mo 掺杂前后的 XRD 图谱；…"}
```

### 两个要素，缺一不可

| 要素 | 规范出处 |
|---|---|
| 图 | ④ 单页信息多则拆两页 |
| 图注（11pt，完整，带上下角标） | ⑦ 必须完整 |

⚠️ **原稿还有第三个要素「提炼条」和橙色 callout 框，我一开始做了，用户说「样本外元素全删，严格照样本」，已经整段删掉。** 想加回来要先问。

### 两种排法，按「放不放得下」自动选

- **A 底栏图注**：图占满宽，图注压底部（原稿 P9/P12/P17）
- **B 右栏图注**：图在左，图注竖排一栏（原稿 P8/P16/P21/P26）

判据是**真的算行数**，不是拍脑袋的字数阈值。详见 `style-tokens.md`。

### 左上角那个竖排章节标签

**只有 B 排法会画**（图从 x=1.35 起，左边空档够宽）；A 排法图从 0.61 起塞不下，原稿 A 排法页也没有。

现在它是**纯文字**：竖排、楷体 11pt、正文色、**没有外框**。外框已被用户要求删掉（2026-11-02：「左上方那个蓝色虚框去一下，不需要了」），但文字保留（「框删了之后里面的字不要删，同时给他从小蓝字变为和正文同字体」）。竖排方向不许改，用户专门反问过「原来的框不是竖着的吗」。

### 图注怎么写（规范⑤⑦）

**图注不是装饰，是听众唯一能回去查的东西。** 组里的通病就是漏图注。

格式：
```
图 3  (a) Mo 掺杂钙钛矿的晶体结构示意；(b) 3+ 价态与 6 价态对比；
(c) 不同掺杂浓度下的 XRD 图谱；(d) (c) 的局部放大。
```
- 开头 `图 N` + 一个空格
- 子图用 `(a) (b) (c)`，每个子图一句，分号隔开
- **化学式必须用 `^{}` / `_{}` 标记**，让脚本转成真上下标：`Cs_{2}NaInCl_{6}` → Cs₂NaInCl₆
- 图注照抄论文原图注可以，但要**译成中文**并补全子图说明

⚠️ **绝对不要**：
- 写「如图所示」就没了
- 只写标题不写子图
- 用 Unicode 上下标字符 `Cr³⁺`（换字体就散，复制到论文里变乱码）
- 图注只写 40 字以内（`check_deck.py` 会报）

### 图注放不下怎么办

**自动续页，续页上必须有完整的「图 + 注」。** 不能只把注挤到下一页 —— 图注和图是一体的，翻页看到一页光秃秃的注没法讲。

## thanks 致谢（规范⑧）

```json
"thanks": {"text": "感谢各位老师批评指正，谢谢大家！", "image": "figs/group.jpg"}
```

固定文案，别自由发挥。`image` 可选（原稿放了张课题组合影）。

## 拆页规则（规范④）

「若单页信息过多可拆分为两页」。判据：

| 情况 | 处理 |
|---|---|
| 一张图有 ≥ 5 个子图 | 拆成两页，(a)-(c) 一页、(d)-(f) 一页 |
| 一页要讲三件以上独立的事 | 拆 |
| 图注放不进任何一栏 | 自动续页（脚本处理） |

**宁可多一页，不要一页塞满。** 听众跟不上是因为一次给太多，不是因为页数少。

用户原话：「你太强迫症了，如果不够放就再多开一页呗」—— 别为了塞进一页去调字号、缩图注。
